# Task Tracker Console Application

.NET 10 Console app solution for the task tracker challenge from roadmap.sh.

Task tracker is a simple command line interface (CLI) project used to track and manage your tasks.

## HOW TO RUN:
dotnet run [command] [--options]

## COMMANDS:
Help: Displays a list of all available commands.

Add: Add a new task
Update: Update an existing task
Delete: Delete an existing task
List: List all tasks
Mark <Status>: Update status of a task to 'in progress', 'done', or 'to do'

Optional Features
List <Status>: List tasks based on status


## INSTALLATION
1. Clone the repository by running the following command:
`git clone https://github.com/erica0926/TaskTrackerCLI`

2. Navigate to the project directory:
`cd task-tracker/TaskTracker`

3. Restore dependencies:
`dotnet restore`

4. Build the project:
`dotnet build`

5. Run the application:
dotnet run
